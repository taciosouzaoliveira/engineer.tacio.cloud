## Kurumin Tecnologia

**Infraestrutura em ordem, sem derrubar o que já funciona.**

Consultoria de infraestrutura Linux, cloud e automação para pequenas e médias empresas. Diagnóstico, implementação, documentação e repasse para a equipe do cliente.

### O que você encontra aqui

Repositórios públicos com modelos e ferramentas que usamos no dia a dia, abertos para qualquer um usar e estudar:

| Repositório | O que faz |
|---|---|
| servidor-em-ordem | Playbook Ansible com a configuração básica de segurança de um servidor Linux |
| backup-testado | Scripts de backup com teste de restauração automático |
| deploy-automatico | Modelo de pipeline de deploy com GitHub Actions e rollback |

### Nossos compromissos

- **Produção é sagrada:** nada vai para o ar sem backup e sem validação.
- **Documentar sempre:** se não está documentado, não foi entregue.
- **Sem dependência:** o objetivo é a equipe do cliente precisar cada vez menos de nós.
